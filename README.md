# NumPy Learning Notes

A collection of Python examples and practice exercises covering the fundamentals of **NumPy**, a Python library for numerical computing and working with arrays.

## 📚 Topics Covered

- Multidimensional Arrays (1D, 2D, and 3D)
- Indexing and Slicing
- Scalar Arithmetic
- Vectorized Arithmetic
- Element-wise Arithmetic
- Comparison Operators
- Array Creation and Manipulation
- Broadcasting
- Aggregate Functions
- Filtering Arrays
- Random Number Generation

## 🛠️ Technologies Used

- Python
- NumPy

## 🚀 Getting Started

**1. Install NumPy**

```bash
pip install numpy
```

**2. Clone the repository**

```bash
git clone https://github.com/nyasa12/numpy-learning-notes.git
```

**3. Navigate to the project folder**

```bash
cd numpy-learning-notes
```

**4. Run the Python file**

```bash
python numpy_basics.py
```

## 💡 How to Use

The examples are organized by topic and enclosed in triple-quoted strings to keep them separate.

- Choose the topic you want to practice.
- Uncomment the corresponding code section.
- Run the Python file and observe the output.
- Experiment with different values to understand how NumPy works.

**Note:** The file produces no output by default because the examples are disabled until you uncomment them.
